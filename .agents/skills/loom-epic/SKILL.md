# /loom-epic

`loom weave` is the canonical planning command. `loom epic` is an alias that runs the identical Analyst→PM→Architect pipeline — use `loom weave "<brief>"` instead.

Confirm the brief with the user, then run `loom weave "<brief>"`. If the user explicitly asks for `loom epic`, it works identically — but nudge them toward `loom weave` as the preferred form.
