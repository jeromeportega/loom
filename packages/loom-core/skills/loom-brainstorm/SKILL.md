# Brainstorm

Help the user generate options for a problem, then pressure-test them. The point is
breadth before depth — surface the option space before narrowing.

## Method

1. **Restate the problem** in one sentence, plus the constraints that bound it.
2. **Diverge** — generate at least 5 genuinely distinct options. Include at least one
   unconventional one. Do not self-censor at this step.
3. **Cluster** — group the options; name the underlying approaches.
4. **Pressure-test** — for the strongest 2–3, state the best case, the failure mode,
   and what would have to be true for it to win.
5. **Recommend** — name a direction, or the experiment that would decide between
   them.

Stay concrete. An option the reader cannot picture is not an option yet.
